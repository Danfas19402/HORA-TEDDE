# ⏱️ HORA TEDDE

### Controle de Horas Trabalhadas

O **HORA TEDDE** é uma aplicação web desenvolvida para facilitar o **registro, acompanhamento e controle das horas trabalhadas**.

O sistema foi pensado para ser simples, rápido e acessível, podendo ser utilizado tanto em **computadores quanto em celulares**.

---

## 📱 Sobre o projeto

O HORA TEDDE permite ao usuário acompanhar sua jornada de trabalho de maneira prática, registrando os horários e consultando as informações da jornada.

A aplicação utiliza tecnologias web e pode ser publicada gratuitamente através do **GitHub Pages**.

---

## 🚀 Funcionalidades

* ⏰ Registro do horário de entrada
* ☕ Registro de intervalos
* 🕐 Registro do horário de saída
* 📊 Controle das horas trabalhadas
* 📅 Acompanhamento da jornada
* 📱 Interface adaptada para celulares
* 💻 Compatível com computadores
* 🌐 Acesso através da internet
* ⚡ Funcionamento diretamente pelo navegador

---

## 🎯 Objetivo do projeto

O objetivo do **HORA TEDDE** é criar uma ferramenta simples para auxiliar no controle da jornada de trabalho, permitindo que o usuário tenha suas informações de horas sempre acessíveis.
